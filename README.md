# Projeto Web — HTML e CSS

Projeto desenvolvido durante meus estudos de desenvolvimento web, com foco na estruturação de páginas usando HTML5 e na estilização com CSS3.

## Sobre o projeto

O site apresenta uma página com seção principal, navegação, serviços e uma galeria de trabalhos. O objetivo é praticar a construção de interfaces e a organização de arquivos de um projeto web.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub

## Estrutura do projeto

```text
site-feito-pelo-youtube/
├── index.html
└── styles/
    ├── styles.css
    └── imagens e ícones
```

## Como executar

1. Clone este repositório:
   `git clone https://github.com/V1NN1B10/projeto-web.git`
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
